# Patagonia: Where Earth Tells Its Story

A responsive, static multi-page website for an Earth Science project about Chilean Patagonia and Torres del Paine.

## Preview locally
1. Unzip this folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension (or use any local static server).
4. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in a browser, but a local server is recommended.

## Publish with GitHub Pages
1. Create a GitHub repository and upload the contents of this folder (not the ZIP itself).
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**.
4. Choose `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish and open the URL shown in Settings → Pages.

This is a plain HTML/CSS/JavaScript site. No build step or package installation is required.

## Pages
- `index.html` — Home
- `about.html` — Personal connection and faith reflection
- `maps.html` — Maps, Location, and Cartographers
- `tectonics.html` — Plate Tectonics, Earthquakes, and Volcanoes
- `erosion.html` — Weathering, Mass Wasting, and Erosion
- `water.html` — Fluvial Processes, Oceans, and Coastlines
- `climate.html` — Climate Controls, Biomes, and Climate Change
- `references.html` — APA-style source list

## Before submitting
- Review the wording and personalize it so it reflects your own research and voice.
- Check every link and page after publishing.
- The photography currently loads from remote Unsplash image URLs. Internet access is required to display it. Review image availability and licensing/attribution requirements for your class; replace images if needed.
- Add any additional instructor-required citations, maps, and researched details.
- The project uses English content and a mobile hamburger navigation menu.

## Design
Palette: deep fjord green, glacier teal, warm off-white, and slate.
Typography: Playfair Display for editorial headings and DM Sans for readable body text.
